# Fonty — Roboto

Pliki TTF w tym katalogu to font **Roboto** (Copyright 2011 The Roboto Project
Authors, licencja Apache License 2.0), wyekstrahowany z wbudowanego
`build/vfs_fonts.js` pakietu `pdfmake` (ten sam font, który pdfmake domyślnie
osadza w wersji przeglądarkowej). Roboto ma pełne pokrycie Latin Extended-A,
czyli poprawnie renderuje polskie znaki diakrytyczne (ą, ć, ę, ł, ń, ó, ś, ź, ż).

Używane przez `server/src/pdf/protocolTemplate.ts` do generowania protokołów
przekazania sprzętu w PDF po stronie serwera (bez przeglądarki).
